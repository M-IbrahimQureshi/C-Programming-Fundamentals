# C Programming Fundamentals

A structured repository documenting my first-semester programming journey in C. This collection tracks my progression from basic input/output and control flow to modular functions, 3D arrays, and low-level memory management with pointers.

## Repository Structure

* **`01-Basics-and-Loops/`**
  * Control flow, ternary operators, nested `switch-case` menus, and loop logic (ATM simulations, eligibility checks, and pattern generation).
* **`02-Functions-and-Arrays/`**
  * Modular programming alongside 1D, 2D, and 3D array manipulation (matrix addition, section-wise mark analysis, hospital ward temperature tracking, and billing systems).
* **`03-Pointers/`**
  * Low-level memory handling, pass-by-reference logic, and structured systems (Bank Management System).

## Tech Stack & Tools
* **Language:** C
* **Environment:** VS Code / Dev-C++
* **Version Control:** Git & GitHub
